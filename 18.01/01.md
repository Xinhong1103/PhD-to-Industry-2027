
# 单变量微积分导论：导数的几何与代数定义

## 导数的核心概念
- **几何解释（切线问题）**：理解曲线在某一点的瞬时变化率。
- **物理意义**：描述物理量随时间的变化速度（如速度、加速度）。
- **广泛应用**：科学、工程、经济学、政治科学等领域的基础工具。
- **目标**：掌握对任意函数（如 ![e^x \arctan x](https://latex.codecogs.com/svg.image?e%5Ex%20%5Carctan%20x)）求导的方法。

---

## 导数的几何解释：切线问题 the slope of the tangent

### 切线定义
- **目标**：找出函数图像在某点 ![P = (x_0, y_0)](https://latex.codecogs.com/svg.image?P%20%3D%20(x_0%2C%20y_0)) 处的切线。
- **切线方程**：
  ![y - y_0 = m(x - x_0)](https://latex.codecogs.com/svg.image?y%20-%20y_0%20%3D%20m(x%20-%20x_0))
  其中：
  - ![y_0 = f(x_0)](https://latex.codecogs.com/svg.image?y_0%20%3D%20f(x_0))
  - ![m = f'(x_0)](https://latex.codecogs.com/svg.image?m%20%3D%20f%27(x_0))：即导数，表示切线的斜率。

### 切线的极限定义
- **思想**：通过割线趋近于点 ![P](https://latex.codecogs.com/svg.image?P) 的极限来定义切线。
- **极限表达式**：
  ![f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}](https://latex.codecogs.com/svg.image?f%27(x_0)%20%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7Bf(x_0%20%2B%20%5CDelta%20x)%20-%20f(x_0)%7D%7B%5CDelta%20x%7D)

## 导数的极限公式推导

### 割线斜率公式
- 设 ![P = (x_0, f(x_0))](https://latex.codecogs.com/svg.image?P%20%3D%20(x_0%2C%20f(x_0)))，![Q = (x_0 + \Delta x, f(x_0 + \Delta x))](https://latex.codecogs.com/svg.image?Q%20%3D%20(x_0%20%2B%20%5CDelta%20x%2C%20f(x_0%20%2B%20%5CDelta%20x)))
- **割线斜率**：
  ![\frac{\Delta f}{\Delta x} = \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}](https://latex.codecogs.com/svg.image?%5Cfrac%7B%5CDelta%20f%7D%7B%5CDelta%20x%7D%20%3D%20%5Cfrac%7Bf(x_0%20%2B%20%5CDelta%20x)%20-%20f(x_0)%7D%7B%5CDelta%20x%7D)

### 切线斜率的极限表达式
- **导数定义**：
  ![f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}](https://latex.codecogs.com/svg.image?f%27(x_0)%20%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7Bf(x_0%20%2B%20%5CDelta%20x)%20-%20f(x_0)%7D%7B%5CDelta%20x%7D)
> 该公式是后续所有导数计算的基础。

## 示例 1：函数 ![f(x) = \frac{1}{x}](https://latex.codecogs.com/svg.image?f(x)%20%3D%20%5Cfrac%7B1%7D%7Bx%7D) 的导数

**题目**：计算函数 ![f(x) = \frac{1}{x}](https://latex.codecogs.com/svg.image?f(x)%20%3D%20%5Cfrac%7B1%7D%7Bx%7D) 的导数。

**分步解答**：
1. **代入函数表达式**：
   ![f'(x_0) = \lim_{\Delta x \to 0} \frac{\frac{1}{x_0 + \Delta x} - \frac{1}{x_0}}{\Delta x}](https://latex.codecogs.com/svg.image?f%27(x_0)%20%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7B%5Cfrac%7B1%7D%7Bx_0%20%2B%20%5CDelta%20x%7D%20-%20%5Cfrac%7B1%7D%7Bx_0%7D%7D%7B%5CDelta%20x%7D)

2. **通分并化简**：
   ![= \lim_{\Delta x \to 0} \frac{-\Delta x}{\Delta x (x_0 + \Delta x)x_0}](https://latex.codecogs.com/svg.image?%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7B-%5CDelta%20x%7D%7B%5CDelta%20x%20(x_0%20%2B%20%5CDelta%20x)x_0%7D)

3. **约去 ![\Delta x](https://latex.codecogs.com/svg.image?%5CDelta%20x) 并取极限**：
   ![= -\frac{1}{x_0^2}](https://latex.codecogs.com/svg.image?%3D%20-%5Cfrac%7B1%7D%7Bx_0%5E2%7D)

**结论**：
![f'(x) = -\frac{1}{x^2}](https://latex.codecogs.com/svg.image?f%27(x)%20%3D%20-%5Cfrac%7B1%7D%7Bx%5E2%7D)

## 应用：切线与坐标轴围成的三角形面积

**题目**：求由函数 ![y = \frac{1}{x}](https://latex.codecogs.com/svg.image?y%20%3D%20%5Cfrac%7B1%7D%7Bx%7D) 的切线与坐标轴围成的三角形面积。

**分步解答**：
1. **切线方程**（在 ![x_0](https://latex.codecogs.com/svg.image?x_0) 处）：
   ![y - \frac{1}{x_0} = -\frac{1}{x_0^2}(x - x_0)](https://latex.codecogs.com/svg.image?y%20-%20%5Cfrac%7B1%7D%7Bx_0%7D%20%3D%20-%5Cfrac%7B1%7D%7Bx_0%5E2%7D(x%20-%20x_0))

2. **x-截距**（令 ![y = 0](https://latex.codecogs.com/svg.image?y%20%3D%200)）：
   ![x = 2x_0](https://latex.codecogs.com/svg.image?x%20%3D%202x_0)

3. **y-截距**（令 ![x = 0](https://latex.codecogs.com/svg.image?x%20%3D%200)）：
   ![y = \frac{2}{x_0}](https://latex.codecogs.com/svg.image?y%20%3D%20%5Cfrac%7B2%7D%7Bx_0%7D)

4. **面积**：
   ![A = \frac{1}{2} \times 2x_0 \times \frac{2}{x_0} = 2](https://latex.codecogs.com/svg.image?A%20%3D%20%5Cfrac%7B1%7D%7B2%7D%20%5Ctimes%202x_0%20%5Ctimes%20%5Cfrac%7B2%7D%7Bx_0%7D%20%3D%202)

> **结论**：面积恒为 2。

## 示例 2：函数 ![f(x) = x^n](https://latex.codecogs.com/svg.image?f(x)%20%3D%20x%5En) 的导数

**题目**：计算 ![f(x) = x^n](https://latex.codecogs.com/svg.image?f(x)%20%3D%20x%5En) 的导数（![n](https://latex.codecogs.com/svg.image?n) 为正整数）。

**推导**：
![f'(x) = \lim_{\Delta x \to 0} \frac{(x + \Delta x)^n - x^n}{\Delta x} = n x^{n-1}](https://latex.codecogs.com/svg.image?f%27(x)%20%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7B(x%20%2B%20%5CDelta%20x)%5En%20-%20x%5En%7D%7B%5CDelta%20x%7D%20%3D%20n%20x%5E%7Bn-1%7D)

**结论**：
![\\frac{d}{dx} x^n = n x^{n-1}](https://latex.codecogs.com/svg.image?%5Cfrac%7Bd%7D%7Bdx%7D%20x%5En%20%3D%20n%20x%5E%7Bn-1%7D)

## 多项式导数规则
- **线性性**：
  ![\\frac{d}{dx}[a f(x) + b g(x)] = a f'(x) + b g'(x)](https://latex.codecogs.com/svg.image?%5Cfrac%7Bd%7D%7Bdx%7D%5Ba%20f(x)%20%2B%20b%20g(x)%5D%20%3D%20a%20f%27(x)%20%2B%20b%20g%27(x))
- **幂法则**：
  ![\\frac{d}{dx} x^n = n x^{n-1}](https://latex.codecogs.com/svg.image?%5Cfrac%7Bd%7D%7Bdx%7D%20x%5En%20%3D%20n%20x%5E%7Bn-1%7D)

**示例**：
![f(x) = x^3 + 5x^{10} \quad \Rightarrow \quad f'(x) = 3x^2 + 50x^9](https://latex.codecogs.com/svg.image?f(x)%20%3D%20x%5E3%20%2B%205x%5E%7B10%7D%20%5Cquad%20%5CRightarrow%20%5Cquad%20f%27(x)%20%3D%203x%5E2%20%2B%2050x%5E9)

## 重点总结
- 导数 = 切线斜率（几何）
- 导数 = 瞬时变化率（物理）
- 极限定义是根本：
  ![f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}](https://latex.codecogs.com/svg.image?f%27(x)%20%3D%20%5Clim_%7B%5CDelta%20x%20%5Cto%200%7D%20%5Cfrac%7Bf(x%20%2B%20%5CDelta%20x)%20-%20f(x)%7D%7B%5CDelta%20x%7D)
- 典型导数：![\\frac{1}{x} \to -\\frac{1}{x^2}](https://latex.codecogs.com/svg.image?%5Cfrac%7B1%7D%7Bx%7D%20%5Cto%20-%5Cfrac%7B1%7D%7Bx%5E2%7D)，![x^n \to n x^{n-1}](https://latex.codecogs.com/svg.image?x%5En%20%5Cto%20n%20x%5E%7Bn-1%7D)
- 面积应用：结果恒为 2。
